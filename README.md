## 内容摘要

### 一、Agent 文章精译

#### 1. Loop Engineering（循环工程）· Addy Osmani

**一句话**：把「给智能体写提示的人」这个角色从你身上拿掉，改为由你设计那套替你写提示的系统。

**核心内容**：循环由五个部件 —— **自动化**（定时发现与分诊）、**工作树**（隔离并行任务）、**技能**（固化项目知识）、**插件与连接器**（接入真实工具）、**子智能体**（制造者与检查者分离）—— 外加一个落在磁盘上的**状态文件**组成。循环替代的只是「你逐步提示」这个动作；验证、理解债、认知投降这三件事仍然由人承担。

**可视化理解图包含**：
1. 全景理解图 —— 「你只设计一次 → 发现 / 分派 / 执行 / 校验 / 记录 → 回到起点」，以及底部的产出；
2. 五部件在 **Codex** 与 **Claude Code** 中的能力对照表；
3. 关键概念卡片 —— 意图债、理解债、认知投降、编排税。

#### 2. Redesigning Source Control（在 Anthropic 重新设计源代码管理）· Anthropic 源代码管理团队

**一句话**：写代码不再是 Anthropic 的瓶颈——为「人类规模」设计的源代码管理、构建和 CI 才是。

**核心内容**：每日合并的代码变更从 2026 年 5 月的约 2,500 个涨到 9 月的 30,000 个以上；主分支历史接近 100 GB，压缩工作副本超过 25 GB，CI 每天要检出约 2,500 万次。团队自研版本控制系统 **Scion**，五个月内把 monorepo 从 git 完整迁走，基础设施占用（CPU + 内存）降到原先几百个内部 git 镜像方案的 **1/200**，检出快了两个数量级（分钟级 → 秒级），仅 CI 就释放出 25% 的 CPU 容量。文章给出四条核心设计原则 —— **客户端始终在线**、**客户端／服务端不对称**、**一切必须能水平扩展**、**提交必须便宜／增量／无锁**、**工作副本可有可无且天生稀疏** —— 以及 changeset + 派生数据的数据结构、分层缓存的检出架构，和四条可以搬回 git 的经验。

**可视化理解图包含**：
1. 全景理解图 —— 负载压力（100 GB 历史 / 25 GB 工作副本 / 2,500 万次检出 / 600 PB 流量）→ git 四个设计前提被逐个替换 → 五个月换来的结果；
2. 检出链路分层缓存图 —— `scn` 客户端 / `scion-daemon` / `scion-cache` / `scion-server` 四层与 Spanner、云存储的关系；
3. 原文 6 张图表按原文顺序保留。

**为什么重要**：这是目前少见的、把「AI agent 规模化写代码之后，开发基础设施会在哪里先断」讲清楚的工程复盘，并且明确指出了哪些部分可以搬回 git。

### 二、读书笔记

#### 1. 置身事内：中国政府与经济发展 · 兰小欢

**一句话**：在我国，政府不但影响「蛋糕」的分配，也参与「蛋糕」的生产 —— 所以不可能脱离政府谈经济。

**核心内容**：全书分上下两篇。**上篇「微观机制」**从事权划分三原则（外部性与规模经济、复杂信息、激励相容）出发，讲 1994 年分税制改革如何造成「财权上收、事权下沉」，地方政府又如何以**土地财政**（卖地补缺口）与**土地金融**（城投平台以地抵押融资）应对，进而形成政府主导的工业化与城市化模式，以及政府产业引导基金这类「政府 + 市场」的混合工具。**下篇「宏观现象」**则把这些微观机制合成为总量后果：房价与债务「一荣俱荣、一损俱损」、中美在「规模不平衡」与「人均平衡」上的镜像关系、银行风险的结构性来源、债务—通缩循环与去杠杆的两个方向、居民消费不足的分解。**第八章**回到政府角色本身，讨论「官场+市场」的激励结构、从生产型政府转向服务型政府，以及组织学习模式与探索创新模式的权衡。

**可视化理解图包含**：
1. 全书主线图 —— 起点（政府参与生产）→ 上篇微观机制 → 下篇宏观现象 → 第八章总结；
2. 问题意识三层次图 —— 是什么 / 为什么 / 怎么办；
3. 全书架构树与「事权 → 财权 → 土地财政 → 土地金融 → 政府投资 → 宏观后果」六步因果链；
4. 上篇逐章图 —— 事权划分三原则、分税制改革因果图、土地金融闭环、政府投资工业的三种方式、私募基金 LP/GP 与引导基金结构；
5. 下篇逐章图 —— 上篇模式三大代价对位、房价与债务链条、中美规模对比、银行风险四个结构性原因、中国债务累积 2008—2018 时间线、化解债务的两个方向、消费不足分解；
6. 章节联系网络总图 + 五组跨章连接表；
7. 总结与转型图 —— 官场+市场机制、生产型政府 → 服务型政府；
8. 核心概念速查表（24 条）与三条阅读路径图。

共 20 张手绘内联 SVG，全篇用一套语义配色（政府／宏观／总结／概念／成就）贯穿，便于定位。

#### 2. 八次危机：中国的真实经验 1949—2009 · 温铁军 等

**一句话**：八次危机不是八件孤立的事，而是同一个机制在六十年里的八次重复 —— 代价总是被转嫁给三农。

**核心内容**：用「去意识形态化」的方式重写当代中国六十年经济史，把 1949 年以来的中国当作一个后发国家的**工业化样本**。核心解释框架是**成本转嫁论**：中国作为后发国家，每一次「引进外资」都伴随一次内生性危机，而危机的成本被制度性地转嫁给农村与农民，从而避免了城市社会的崩解。书中以**四次引进外资 × 八次危机**的对照表作为最硬的一张证据，梳理出两个规律性发现，并追踪三农功能的三次历史性变化，逐次解说八次危机的成因、过程与后果，最后附上 1949—2011 的分阶段大事年表与书中引用的关键数据。

**可视化理解图包含**：
1. 问题意识图 —— 三个追问（外资是工具还是负债起点 / 为什么中国危机没有引发制度崩解 / 意识形态化的左右之争遮蔽了什么）；
2. 变量模型图 —— 五个关键变量与「成本转嫁论」解释框架；
3. 四次引进外资 × 八次危机对照表；
4. 八次危机逐次解说与一览图（按四阶段着色，标出危机爆发年）；
5. 三农功能三次历史性变化图；
6. 分阶段大事年表时间线与关键数据摘录；
7. 全书逻辑闭环图与三条「读法」。

共 11 张理解图。

**为什么值得并列阅读**：两本书都在回答同一个问题的两面 —— 《置身事内》拆的是**政府怎么参与经济**（财政、土地、债务的微观机制），《八次危机》拆的是**这套机制在六十年里付出过什么代价**（危机与成本转嫁的宏观史）。前者给横截面，后者给时间轴。

## 新增一份内容的流程

1. **翻译 / 精读**：文章用本地 `baoyu-translate` 技能产出中文精译，并过一遍 `markup_fidelity.py` 标记保真门禁（超链接、图片、加粗、脚注标记不得静默丢失）；书籍则逐章精读后整理。
2. **判断重要性**：先判断这份内容是否值得收录（是否触及关键议题、是否有一手细节、是否会被反复引用）。
3. **征询同意**：若判断为重要，先向用户询问，获得同意后再上传；不擅自发布。
4. **独立检查与润色**：正式上传前，单独做一遍逐段对照原作的复核 —— 术语一致性、错别字、标点与空格、长句可读性、标题层级与图注质量。
5. **打包**：按仓库约定生成自包含 HTML 放在仓库**根目录**，补上手写内联 SVG 理解图，并按命名约定命名。
6. **发布**：推送到 `main` 分支，触发 GitHub Pages 重新构建，回访线上页面确认排版正常，并把这一份加到首页画廊（`index.html`）与上方清单。
